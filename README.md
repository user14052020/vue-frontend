# Управление учетными записями
<img width="1656" height="731" alt="Screenshot 2026-02-03 at 11 59 53" src="https://github.com/user-attachments/assets/28945fdd-66a4-4287-a93a-d5ddb7bb093d" />

Тестовое задание: форма управления учетными записями с валидацией, сохранением в Pinia и восстановлением после перезагрузки.

## Стек
- Vue 3 + Composition API
- TypeScript
- Pinia
- Tailwind CSS
- Vite

## Функциональность
- Добавление учетной записи кнопкой `+` (в конец списка).
- Удаление учетной записи из списка.
- Валидация на `blur` для текстовых полей и на изменение для селекта.
- Поле «Метки» допускает несколько значений через `;` и сохраняется как массив `{ text: string }`.
- Поле «Пароль» отображается только для типа `Локальная`, для `LDAP` хранится как `null`.
- Данные сохраняются в `localStorage` через Pinia.

## Структура (FSD)
```
src/
  app/                # инициализация приложения
  pages/              # страницы
  widgets/            # крупные блоки интерфейса
  entities/           # сущности и модели
  features/           # прикладная логика (в данном проекте минимально)
  shared/             # типы, утилиты, базовые UI
```

## Организация файлов
- Скрипты и стили вынесены из `.vue` файлов в отдельные каталоги `scripts/` и `styles/` рядом с компонентом.
- В `.vue` остаются только шаблоны и ссылки на внешние файлы через `src`.

## Локальный запуск
1. Установить зависимости:
```
npm install
```

2. Запуск dev-сервера:
```
npm run dev
```

3. Сборка:
```
npm run build
```

## Запуск в Docker
1. Сборка образа:
```
docker build -t account-manager .
```

2. Запуск контейнера:
```
docker run --rm -p 8082:80 account-manager
```

Приложение будет доступно на `http://localhost:8082`.

## Примечания по данным
- Валидные записи сохраняются в `localStorage` по ключу `account-manager.records`.
- При перезагрузке отображаются только ранее сохраненные валидные записи.
